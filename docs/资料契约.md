# 文化素材许可的用量解释与续约承保资料约定

以下记录全部为本地合成数据，业务名称、参与方及数量不对应真实企业。

日期使用公历，带Z的时间为UTC。缺失值使用JSON null，空列表表示已知集合为空。资料主键仅表示该来源记录身份，业务版本与原始对象字段另行保留。

USD金额单位为美分。保底用于抵扣同范围后续按量许可费，不能保底与全部按量款重复累加。
衍生作品在release用途须有自身与所有可达原作的地域许可。preview用途仅表示编辑预览，不产生正式发行权。
发行存续结束且日志覆盖完整的批次为完整观察批次，未结束或覆盖不足的批次不等于零用量。
authorization_events仅记录各方原始动作，不预先判定合同是否成立。归属裁决从所列日期生效，既有合同须据其当时授权解释。

## works

原作及衍生谱系。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| id | str | 作品 |
| kind | str | 类型 |
| parents | list | 原作引用 |
| owner | str | 登记权利人 |

## licenses

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| id | str | 许可 |
| work | str | 作品 |
| customer | str | 客户 |
| territories | list | 地域集合 |
| purpose | str | 用途 |
| from | str | 起日 |
| to | str | 末日 |
